# Student Marks Calculator

A simple beginner-friendly Python project that calculates a student's total marks, percentage, and grade.

## Features

- Takes the student's name.
- Accepts marks for five subjects.
- Checks that each mark is between 0 and 100.
- Calculates total marks and percentage.
- Displays a grade based on the percentage.
- Prints a clear marks report.

## Requirements

- Python 3
- No extra libraries are required.

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

   On some computers, use `python3 main.py`.

4. Enter the student's name and marks when asked.

## Grade System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| Below 50% | Fail |

**Note:** This is a sample grading system for a student project. Actual grade rules may differ by school or college.

## Example

If the student scores 90, 85, 78, 92, and 80:

- Total: 425 / 500
- Percentage: 85.00%
- Grade: A
